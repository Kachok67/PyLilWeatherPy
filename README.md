A basic Weather fetching app which fetches json code from Open-Mateo API and displays data in a nice graphical (tkinter library) and command line interface.

Usage: Use anything above Python 3.10 (not tested on older versions of interpreter), you can choose to enter following arguments:
Argument 1: if no-ui then no UI will be initialised and only the command line will display weather data.
Argument 2: The modifier of the font size (int, non floating point values can be entered). Standart font size will be multiplied by it.
